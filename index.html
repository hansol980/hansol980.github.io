Undergraduate student, Department of Applied Artificial Intelligence, Hansung University

I study how data leaks from machine learning models and how it can be removed from them — from gradient leakage attacks in federated learning to machine unlearning in large language models. I am preparing to pursue graduate study in trustworthy and privacy-preserving machine learning.

Email GitHub

Research Interests

My questions follow the lifecycle of private data inside a model: how it leaks during training, how it can be erased afterwards, and how we can verify that it is truly gone.

01 · LEAKAGE

Privacy Attacks in Federated Learning

How shared gradients and visible graph context reveal private node features in federated graph learning.

02 · REMOVAL

Machine Unlearning for LLMs

Removing specific knowledge from a trained language model without retraining it from scratch.

03 · VERIFICATION

Evaluating Unlearning

Does an unlearned model really forget? Testing unlearning against extraction, membership inference and relearning.
